# Biblioteca POO — Exercícios de Prática

Repositório de estudos em PHP puro (sem framework), praticando **Programação Orientada a Objetos (POO)** 

## Objetivo

Treinar a criação de classes, propriedades, construtores e objetos, entendendo o que o Laravel faz "por baixo dos panos".

## Classes praticadas

- **Livro** — `titulo`, `autor`, `ano`
- **Casa** — `cor`, `numeroDeQuarto`, `numeroDeBanheiro`
- **Carro** — `cor`, `modelo`, `numeroDeBancos`

Cada classe tem um construtor (`__construct`) que recebe os dados e os guarda no objeto criado, usando `$this`.

## Conceitos praticados

- Declaração de classe (`class`)
- Propriedades tipadas (`public string`, `public int`)
- Construtor (`__construct`)
- `$this` para acessar o objeto atual
- Criação de objetos (`new`)
- Acesso a propriedades com `->`
- `echo` e concatenação (`.`)

## Como rodar

```bash
php nome-do-arquivo.php
```
